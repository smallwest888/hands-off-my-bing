Hands Off My Bing — Privacy

Updated October 19, 2026 (version 1.2.11)

Stored on this device

The extension stores the four display choices, automatic-apply switch, delay, and interface language locally. It does not read search text, page content, cookies, account details, or request bodies, and sends no data to a developer or analytics server.

Temporary tab information

Managed tab identifiers are kept only for the current browser session. The extension briefly checks the URL and state of tabs it opens. A URL may include a query, but only its site and path are used to recognize a supported homepage; query values and search terms are not extracted, and URLs are not saved as browsing history.

How news is handled

When automatic apply is on and News is Off, the extension blocks background requests to a specific carousel endpoint only in the single tab it manages. Other content is not broadly blocked; other hiding uses removable styles. Bing continues to connect normally and manages its native preferences.

New tabs and restoring Chrome

The extension replaces Chrome’s new-tab page. Pausing does not restore Chrome’s default page; disabling or uninstalling it does. Pausing or uninstalling does not undo display settings already saved in Bing.

Focus protection

During startup, search-box focus protection lasts at most 20 seconds. If the page loses focus during automatic apply, a separate temporary guard may also run for up to 20 seconds. Neither reads typed text, and timing can still cause missed characters.

Supported sites and project

The extension runs only on the HTTPS root pages of www.bing.com, cn.bing.com, and bing.com, with limited permissions. It uses no remote code, ads, or analytics. It is an independent project with no affiliation with or endorsement by Microsoft, Bing, or Google.
